# Kiểm thử nhanh skill cho Use Case 1 và Use Case 2

Thư mục này chỉ dùng dữ liệu mẫu hoặc truy vấn giới hạn nhỏ để xác nhận các skill trong giáo án có thể được gọi đúng cách.

- `uc1-apify/`: chạy thử chế độ xem trước và pipeline dữ liệu giả, không gọi Actor Apify.
- `uc2-youtube/`: lưu JSON từ một truy vấn YouTube giới hạn nhỏ.
- `results/`: báo cáo kiểm thử và đầu ra từ các skill vận hành bằng prompt.

Không đặt token, cookie hoặc dữ liệu doanh nghiệp thật trong thư mục này.
