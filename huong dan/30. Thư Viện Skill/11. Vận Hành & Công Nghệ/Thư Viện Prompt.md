# Thư Viện Prompt

Sắp xếp và ghi lại thư viện prompt tái sử dụng: phân loại, các biến thay thế và cách chấm điểm chất lượng. Dùng khi muốn cả đội dùng chung một bộ prompt chuẩn thay vì mỗi người tự nghĩ.

## Gọi thế nào

Gõ `/prompt-library` trong Claude, hoặc mô tả việc muốn làm bằng tiếng Việt — Claude tự nhận skill này.
